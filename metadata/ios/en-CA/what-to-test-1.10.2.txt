A new install now summarizes on-device with Apple Intelligence by default. Ollama is opt-in, and on a device that cannot run Apple Intelligence the app falls back to Ollama and says why. A provider you already chose is kept exactly as it was. Settings also accepts an optional Ollama Server URL, so summaries, Quick, Deep and speech correction can use an Ollama server you run on your own network instead of ollama.com; no API key is needed for your own server and a saved Ollama Cloud key is never sent there. Use the computer's .local name; a numeric address such as 192.168.1.10 over plain http is refused with a hint.

Please test: on a fresh install, open More → Settings and confirm the summary provider is Apple Intelligence (or Ollama with a stated reason on an ineligible device), then generate a summary without entering any key. Update from an earlier build and confirm your previous provider, models and API key are unchanged. Switch to Ollama, leave Server URL blank and confirm requests still go to https://ollama.com. Then enter your own server, for example http://your-mac.local:11434, allow local network access, refresh models, choose one and summarize; confirm the Server line and status text name that address. Try http://192.168.1.10:11434 and confirm it is refused with a message pointing at the .local name. Type https://ollama.com by hand and confirm it is treated as Ollama Cloud, not as your own server. Enter an invalid address and confirm it is rejected and the previous server is kept, then tap Use Ollama Cloud instead. Check that Auto Quick Summary explains that it needs Ollama while Apple Intelligence is selected.
