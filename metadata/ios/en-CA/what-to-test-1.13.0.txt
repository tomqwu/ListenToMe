This build adds Save to folder, lets Automatic language switch more than once in a recording, lists every language your device can transcribe, keeps speaker names through long silences, adds OpenAI-compatible servers for summaries, and lists open-source licenses. Transcription, language checks and speaker labels still run on this device.

Please test:
1. Record a conversation of 30 minutes or more with two or three people, where someone stays quiet for several minutes. Rename the speakers in Notes → Speakers. When the quiet person speaks again, their lines keep the same label and name instead of becoming a new Speaker.
2. Open More → Settings → Transcription → Language. The list is grouped as Installed and Downloadable. Pick a language that was not in the list before (for example Portuguese, Italian or Hindi), record a little in it, and check the transcript. Set it back to Automatic afterwards.
3. Turn on More → Settings → Save to folder and pick a folder in Files: an Obsidian vault or an iCloud Drive folder. Record, then tap Stop. Open the folder in Files or Obsidian: one Markdown note for the conversation appears. Generate a summary or change the title; the same note updates instead of a second one appearing.
4. With Automatic language on, speak one language for about two minutes, then switch to another and keep talking. Within about two minutes the status reads "Detected … from … · switched" and only the part since the change is written again. A short phrase in another language does not switch. Tap Undo: it goes back to the language before the latest switch.
5. Optional: choose OpenAI-compatible as the summary provider and enter a server you run, such as LM Studio at http://your-mac.local:1234/v1. Refresh models, pick one for each role, tap Test connection, then generate a summary. Settings says "your server" for your own network and "may leave this device" for a hosted service.
6. Open More → Settings → About → Acknowledgements. Each open-source package is listed, and tapping one shows its license.
