# Watch review previews

Native English (US) captures of the existing Watch app: [Series 11, 46 mm](series11-46-home.png) (416 × 496) and [Ultra 3, 49 mm](ultra3-home.png) (422 × 514). The installed watchOS 26.5 runtime cannot create Series 12 or Ultra 4 simulators. These filenames identify the models actually captured.

These images are saved for maintainer review. **iOS 1.18.1 build 36 does not contain the Watch app**, so these are not customer listing uploads or evidence of shipped Watch support. A Watch-enabled build must pass the separate #181 release gates before its screenshots can be submitted.

Both existing native denied-microphone/offline UI tests passed. The complete external evidence includes original attachments, recovery diagnostics and command logs. The two home images preserve native resolution without resizing; [provenance](provenance.json) records hashes and source. No microphone recording or physical-device transfer was performed. Temporary simulators were deleted.
